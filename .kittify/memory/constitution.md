## Purpose

This constitution captures the technical standards and governance rules for

## Technical Standards

### Languages and Frameworks

- **PHP 8.5+** — target the latest PHP with full use of modern language features
- **PHPStan level 8** (eventual target) — full static type analysis with no baseline suppressions
- **Psalm taint enforcement** — security-sensitive data flows must pass taint analysis
- **Type strictness goal**: types should be as explicit and narrow as possible, comparable to what you'd write in Java or Kotlin. Prefer union types, intersection types, and generics over `mixed`. Avoid `mixed` except at true system boundaries.
- **PSR-4 autoloading** via Composer, namespace root `WTForms\`
- No framework dependency — standalone library

### Testing Requirements

- **PHPUnit 9+**
- **80%+ line coverage** minimum
- All public API methods must have corresponding test coverage
- Tests mirror source structure in `tests/`

### Performance and Scale

Not a primary concern. This is a form-handling library; correctness and type safety take priority over micro-optimization.

### Deployment and Constraints

- Distributed as a **Composer package** via Packagist
- No platform-specific requirements
- Development environment uses Docker devcontainer (see `.devcontainer/`)
